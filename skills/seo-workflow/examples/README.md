# Examples

Sample outputs from one free run of the `seo-workflow` skill, for a made-up invoicing company (acme-invoicing.com). Your own run produces files like these for your real site.

- **[../assets/dashboard.html](../assets/dashboard.html)** is the main deliverable, shown here with the sample data. Open it in a browser. It holds the site audit, a sortable keyword table with a CSV export button, the 30-day content calendar, the article preview and the next step. The skill uses this file as its template and swaps in your data, so the styling stays the same.
- **sample-article.md** is the full article the skill writes: one finished, fact-checked piece, ready to publish. It shows the quality bar.
- **keywords.csv** is what the dashboard's "Export CSV" button produces.

The data here is illustrative. Volumes are labelled as estimates because the free skill has no measured search data. Measured volume comes with [The SEO Agent](https://www.theseoagent.ai/?utm_source=skill&utm_medium=github&utm_campaign=ai-seo-agent&utm_content=seo-workflow-examples).
