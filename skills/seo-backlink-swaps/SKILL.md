# SEO backlink swaps

Find relevant sites to approach for a link swap, using web search. Free, no key, no account. This skill never calls The SEO Agent's servers or any paid API.

Be honest about the limit: you can find and qualify candidates, but you cannot arrange a real exchange on the user's behalf.

## 1. Find relevant, non-competing sites

For the site's niche, search for sites that publish to the same audience without selling the same thing:

- `<niche> blog`, `<niche> resources`, `best <niche> blogs`
- `<niche> "write for us"`, `<niche> "guest post"`, `<niche> "contribute"`
- Roundups and resource pages: `<niche> "useful resources"`, `<topic> tools list`

## 2. Qualify each candidate

For each one, note what they publish, whether they are a direct competitor (skip those), whether they look active (recent posts), and a contact or submission path if one is visible.

## 3. Hand back a shortlist

Return 10 to 20 qualified candidates with the URL, why they fit, and the contact path. For each, suggest a specific page on the user's site that would be a genuinely useful link target.

## What this skill will not do

- It will not make up domain authority, traffic or backlink counts. Those need measured data.
- It will not send outreach emails or contact anyone. The user decides who to approach and writes to them.
